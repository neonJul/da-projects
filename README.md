# Data Analytics Portfolio

Hi, I'm Nila Sisakyan, a Data Analyst with a Senior Software Engineer background and 8+ years of experience in product development.

This repository showcases selected analytics projects covering user behavior, A/B testing, seasonal demand, and market analysis. Each project includes the business question, data preparation, analytical methods, findings, and recommendations.

## Projects

| Project | Objective | Methods and Tools |
| --- | --- | --- |
| [Recommendation Algorithm A/B Test](./recommendation-ab-test/) | Plan and analyze an experiment evaluating first-session engagement under a new recommendation algorithm. | Python, pandas, Matplotlib, statsmodels, sample size estimation, proportion testing |
| [E-commerce Conversion A/B Test](./ecommerce-ab-test/) | Evaluate a website interface experiment and assess purchase conversion against a business target. | Python, pandas, statsmodels, experiment validation, conversion analysis |
| [Yandex Afisha: User Behavior and Seasonal Demand](./ticketing-analysis/) | Explore seasonal ticket demand and compare mobile and desktop user behavior. | Python, pandas, NumPy, Matplotlib, seaborn, SciPy, EDA, Welch’s t-test |
| [Venture Investment Market Analysis](./venture-investments/) | Analyze historical startup funding, market segments, and funding trends to inform an investment strategy. | Python, pandas, Matplotlib, seaborn, data preprocessing, feature engineering, outlier analysis |

Each project folder includes a Jupyter Notebook and a README describing the objective, datasets, analysis, and findings.
